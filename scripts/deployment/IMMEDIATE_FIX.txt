================================================================================
COMMON ISSUES
================================================================================

1. Virtual environment not activated
   → Make sure you run: source venv/bin/activate

2. Wrong directory
   → Find it: find / -name "realestate1-backend" -type d 2>/dev/null

3. Service not enabled
   → Run: sudo systemctl enable gunicorn
   → Then: sudo systemctl start gunicorn

4. Port conflict
   → Check: sudo lsof -i :8000
   → Kill if needed: sudo kill -9 <PID>
