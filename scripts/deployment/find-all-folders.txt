======================================================

COMMAND 3: Find all git repositories
=====================================
find /var/www /root /opt /home -name ".git" -type d 2>/dev/null | sed 's/\.git$//'


COMMAND 4: Find all Node.js projects (package.json)
====================================================
find /var/www /root /opt /home -name "package.json" -type f 2>/dev/null | xargs dirname


COMMAND 5: Find all Python/Django projects (manage.py)
=======================================================
find /var/www /root /opt /home -name "manage.py" -type f 2>/dev/null | xargs dirname

COMMAND 7: List all systemd service files
==========================================
ls -la /etc/systemd/system/ | grep -E 'gunicorn|django|realestate|nextjs|node'
