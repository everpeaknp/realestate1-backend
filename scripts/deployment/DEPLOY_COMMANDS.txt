================================================================================
TROUBLESHOOTING
================================================================================

If you can't find directories:
-------------------------------
find / -name "realestate1-*" -type d 2>/dev/null


If services won't restart:
---------------------------
# Check what's running
sudo systemctl list-units --type=service | grep -E 'gunicorn|nginx'
pm2 list

# Restart nginx
sudo systemctl restart nginx


View logs:
----------
# Backend logs
sudo journalctl -u gunicorn -n 50
tail -f /var/log/gunicorn/error.log

# Frontend logs
pm2 logs realestate1-frontend

# Nginx logs
sudo tail -f /var/log/nginx/error.log
